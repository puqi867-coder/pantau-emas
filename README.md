# 🪙 Pantau Emas - Android App

Aplikasi Android modern untuk memantau harga emas secara real-time, menghitung estimasi keuntungan/kerugian (Profit/Loss Calculator), serta mengelola portofolio investasi emas Anda.

![Pantau Emas Banner](assets/banner.jpg)

## ✨ Fitur Utama
- 📊 **Pantau Harga Emas Real-time**: Monitoring grafik pergerakan harga emas terkini dengan berbagai rentang waktu.
- 🧮 **Kalkulator Untung/Rugi**: Simulasi profit & loss investasi emas berdasarkan harga beli dan harga pasar saat ini.
- 💼 **Portofolio Emas**: Catat dan lacak kepemilikan emas dari berbagai pecahan (denominasi) dan provider.
- 🔔 **Notifikasi & Tips**: Dapatkan update tips seputar investasi emas dan pergerakan pasar.
- 🎨 **Modern Jetpack Compose UI**: Desain antarmuka responsif dan bersih dengan Material 3.

## 📥 Download & Instalasi
File APK siap instal tersedia di repositori ini dan halaman **Releases**:
- **[Download Pantau-Emas-debug.apk](./Pantau-Emas-debug.apk)**

### Cara Pasang di Android:
1. Download file `Pantau-Emas-debug.apk` ke perangkat Android Anda.
2. Buka file APK melalui File Manager.
3. Izinkan *"Install from Unknown Sources"* jika diminta.
4. Selesaikan instalasi dan buka aplikasi.
